## Project Experience

### Classification of Brain Tumor  
2024

Developed a deep learning-based CNN model to detect and classify brain tumors using MRI scans.

- Used MRI image data for model training and evaluation
- Classified brain tumors into four categories:
  - Glioma
  - Meningioma
  - Pituitary Tumor
  - No Tumor

### Real-time Gait Measurement Device  
2023

Developed a lightweight and portable gait measurement device using pressure sensors attached to shoes.

- Designed a wearable foot pressure measurement system
- Used AVR and Bluetooth communication for real-time data transmission
- Implemented Python-based software for graphical visualization
- Visualized foot pressure distribution using color-mapped analysis

### Bio-signal Based Stress Monitoring System  
2023

Developed a real-time stress monitoring system based on bio-signal analysis.

- Measured and analyzed multiple bio-signals
- Detected stress and relaxation states
- Explored the use of physiological signals for real-time health monitoring
